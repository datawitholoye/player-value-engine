# Player Value & Retention Engine

Predicts each player's future value and churn risk for a betting operator, and **blocks retention offers to players showing signs of gambling harm**.

> Status: in progress. Week 1, data generation done; SQL feature layer next.

## Why this project

Operators use player value (CLV) models to decide who gets retention offers. A naive model learns that players with escalating stakes are "high value", and those are often the players most at risk of harm. This project builds the value and churn models **and** a safer gambling guardrail, so commercial targeting never rewards harmful play.

## Data

All data is **synthetic**, generated by `src/pve/generate_data.py`. No real customer data is used.

| Table | Rows (default) | What it holds |
|---|---|---|
| `players` | 20,000 | signup date, age band, region, acquisition channel |
| `bets` | ~6.3M | timestamp, product (sports/casino), stake, odds, returns |
| `deposits` | ~700k | deposit attempts, amount, success/failed |

Players come from four hidden segments (casual, regular, VIP, at-risk). At-risk players show realistic harm markers: escalating stakes, late-night play and failed deposits. The `_true_*` columns are for validation only and are never used as model features.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
python -m pve.generate_data      # writes data/raw/*.parquet
pytest -q                        # 5 tests should pass
```
